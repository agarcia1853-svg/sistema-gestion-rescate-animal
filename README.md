
# Sistema de Gestión de Casos de Rescate Animal

## Descripción
Proyecto académico orientado al diseño y desarrollo de un sistema
para gestionar casos de animales rescatados, organizar su atención
y facilitar el seguimiento de los casos registrados.

## Unidad 1
Diseño y arquitectura del sistema, documentación y diagramas
del proyecto.

## Unidad 2
Construcción del prototipo estructural mediante HTML5.

## Páginas del prototipo
- index.html: panel principal del sistema.
- reportar.html: formulario para registrar animales rescatados.
- rescates.html: listado de casos registrados.

## Tecnologías
- HTML5
- Git
- GitHub
- Visual Studio Code

## Ramas de trabajo
- main: versión principal.
- develop: integración de avances.
- feature/maquetacion-html: desarrollo de la maquetación HTML5.
